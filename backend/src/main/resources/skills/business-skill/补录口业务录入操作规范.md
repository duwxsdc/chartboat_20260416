# 补录口业务录入操作规范（业务录入人员版）
## 1. 规范总则
为确保补录数据合规、准确、可追溯，业务录入人员需严格遵循本规范，违规操作可能导致数据异常、审核失败，影响业务流程。

## 2. 录入基础规范
### 2.1 数据填写规范
- 必填项（标红字段）必须填写，不可空项、漏项；非必填项按实际情况补充
- 数据格式需符合要求：日期格式（YYYY-MM-DD）、数值格式（保留指定小数位）、文本格式（不可输入特殊字符）
- 填写内容需真实、准确，与实际业务数据一致，禁止编造、篡改数据
- 涉及附件上传：附件需清晰、完整，格式符合要求（如PDF、Excel），命名规范（业务类型+日期+姓名）

### 2.2 操作行为规范
- 登录后及时锁定账号，离开工位需退出登录，禁止共享账号、转借账号
- 仅可操作自己权限范围内的补录口，禁止越权访问其他补录口
- 补录过程中若需暂停，可保存草稿，避免数据丢失；草稿保存期限为3个工作日
- 提交补录数据后，及时查看审核状态，若审核驳回，按驳回意见修改后重新提交

### 2.3 禁止行为
- 禁止填写虚假数据、无效数据
- 禁止篡改已提交、已审核的补录数据
- 禁止删除补录记录、草稿数据
- 禁止截图、下载、外发补录相关数据及页面信息
- 禁止随意点击非业务相关的菜单、按钮，避免误操作

## 3. 特殊场景规范
- 批量补录：需按系统提示的批量模板填写，确保数据格式统一，避免批量失败
- 逾期补录：需提前联系ITBA责任人说明原因，按指引完成补录，避免影响业务进度
- 数据修改：未审核的补录数据可自主修改；已审核的数据需联系审核人或ITBA协助处理
