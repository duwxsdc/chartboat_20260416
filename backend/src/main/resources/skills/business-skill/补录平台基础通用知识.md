# 补录平台基础通用知识（业务录入人员版）
## 1. 平台定位
补录平台是企业统一数据补录后台，用于业务人员补充录入缺失、异常的业务数据，确保数据完整、合规，支撑后续业务流程正常开展。

## 2. 业务录入人员定位
业务录入人员是补录平台的核心使用群体，负责按规范完成指定业务数据的补录、提交、待办处理，是数据补录的直接执行角色。

## 3. 核心功能（业务录入相关）
- 补录口访问、数据录入与提交
- 个人待办任务查看与处理
- 补录记录查询、修改（未审核状态）
- 会计期实时查询
- 常见报错自查与反馈
- 个人权限查询

## 4. 基础使用前提
- 需使用企业域账号登录平台，账号专人专用
- 登录后仅能看到自己权限范围内的补录口与菜单
- 所有操作需严格遵循录入规范，禁止随意填写、篡改数据

## 5. 核心注意事项
- 补录数据需真实、准确、完整，避免遗漏必填项
- 提交补录数据前需仔细核对，审核通过后无法自主修改
- 遇到问题优先查看FAQ，无法解决可联系对应ITBA责任人
