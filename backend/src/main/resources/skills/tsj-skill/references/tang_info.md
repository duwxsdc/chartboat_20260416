# 唐上君老人详细资料

## 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 唐上君 |
| 出生年份 | 1927年 |
| 年龄 | 96岁（截至2023年） |
| 籍贯 | 湖南省雾寒村 |
| 职业 | 退休人民教师 |
| 退休金 | 4000多元/月 |
| 标志性场所 | 同心书楼（二楼阁楼） |

## 人生经历

### 求学阶段
- 家境贫困，但在父母支持下坚持读书
- 23岁时考入城里的学校

### 教师生涯
- 成为人民教师
- 一边教书一边参与建校工作
- 生活极度节俭：每天只吃一顿饭，衣服破了补了又补
- 被学生称为"补丁老师"
- 婚后育有3个孩子，因全身心投入工作与家人聚少离多

### 退休返乡
- 退休后放弃城市安逸生活
- 执意回到偏僻的雾寒村
- 将自家二楼阁楼改建为"同心书楼"
- 开设免费补习班，走访全村动员家长送孩子来补课

## 主要贡献

### 教育成就
- 多年教出50多位大学生
- 成功劝回想弃学打工的偏科女孩，助其考上大学并进入银行工作
- 帮助沉迷手机游戏的留守儿童戒掉网瘾

### 振兴乡村
- 呼吁大学生支教
- 亲自登门拜访，以诚意打动曾在外面教书的女邻居回村任教
- 将退休工资全部捐给学校
- 把家里的图书搬到学校供孩子们使用

## 创新教学方式

- 利用烟盒制作教具
- 制作钉子板吸引孩子兴趣
- 根据留守儿童心理特点进行引导，而非单纯说教

## 人物评价

### 村民评价
"蠢、怪、傻"——村民最初的误解，实际上是对其无私行为的反讽敬佩

### 自我信条
> "子孙若如我，留钱做什么......"
> ——林则徐名言（唐上君以此为家训，不留给子孙钱财，留给精神财富）

### 精神品质
- **无私奉献**：完全免费教学，倒贴退休金
- **生活简朴**：一生保持艰苦朴素作风
- **执着敬业**：96岁高龄仍坚持在教学一线
- **教育智慧**：善于引导而非说教
- **家风传承**：大儿子最终理解并退休后来村照顾其起居

## 核心主旨

"春蚕到死丝方尽"的崇高师德和无私大爱，展现老一辈知识分子对乡村教育的坚守。

## 典型案例

### 案例一：偏科女孩
一名女孩因偏科严重想弃学打工，唐上君成功劝回，助其考上大学并进入银行工作。该女孩至今每年都会回村看望老人。

### 案例二：网瘾留守儿童
7岁男孩乐乐沉迷手机游戏，唐上君通过自制教具等方式帮助其戒掉网瘾，爱上学习。
