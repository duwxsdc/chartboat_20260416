# 补录口基础信息查询（业务录入人员版）
## 1. 查询范围
业务录入人员可查询自己有权限访问的补录口相关基础信息，用于快速定位补录口、解决基础咨询问题，无需额外联系ITBA。

## 2. 可查询的基础信息
### 2.1 补录口核心信息
- 补录口名称、业务类型（如：财务数据补录、业务单据补录）
- 所属租户（明确当前补录口对应的业务租户，避免跨租户操作）
- 补录口状态（正常、暂停、关闭）
- 可补录会计期范围

### 2.2 菜单访问信息
- 补录口所在菜单路径（如：补录管理 → 财务补录 → 费用补录口）
- 访问方式（登录后直接通过菜单进入，或通过待办任务跳转）
- 关联功能（如：附件上传、草稿保存、批量补录）

### 2.3 责任人信息
- 对应ITBA责任人（姓名、联系方式）：负责该补录口的配置支撑、问题答疑
- 审核责任人（姓名、联系方式）：负责该补录口补录数据的审核

## 3. 查询流程
### 3.1 补录口基础信息查询
1.  登录平台 → 点击【补录管理】菜单
2.  找到目标补录口，点击“详情”按钮
3.  页面显示该补录口的租户、业务类型、状态、会计期范围等信息

### 3.2 菜单路径查询
1.  登录平台 → 点击【补录管理】菜单
2.  鼠标悬浮在目标补录口名称上，会显示完整菜单路径
3.  若无法找到补录口，可通过【补录管理】→ 【补录口搜索】，输入名称快速定位

### 3.3 责任人查询
1.  方法一：补录口详情页面，查看“ITBA责任人”“审核责任人”信息
2.  方法二：登录平台 → 点击【帮助中心】→ 【责任人查询】，按补录口名称筛选
3.  方法三：直接联系本部门ITBA责任人咨询

## 4. 注意事项
- 仅能查询自己有权限的补录口基础信息，无权查询其他补录口信息
- 若责任人信息变更、补录口状态异常，及时联系本部门ITBA责任人
- 补录口关闭后，无法访问，需联系ITBA责任人确认是否可重新开通
