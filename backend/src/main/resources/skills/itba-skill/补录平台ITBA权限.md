# 补录平台 ITBA 权限说明
## 1. 权限体系
平台采用角色化权限管控，按岗位最小化分配权限，实现权责隔离、合规管控。

## 2. ITBA 拥有权限
- 菜单权限：配置管理查询、权限查询、操作日志、帮助中心、知识库查看
- 操作权限：配置信息查看、规则查阅、权限清单浏览、业务问题指导
- 文档权限：操作手册、职责说明、FAQ、规范文档查阅

## 3. ITBA 无权限范围
- 高危配置：配置删除、批量修改、强制下线、新增高危配置
- 数据能力：数据导出、明细下载、批量打印、数据脱敏外发
- 特殊权限：跨部门授权、临时白名单、超级管理员权限
- 流程干预：审批强制通过、流程撤回、历史单据篡改

## 4. 权限申请通用流程
1. 申请人明确使用场景、所需菜单及操作能力
2. 参照平台规范准备申请材料
3. 部门负责人审批通过后，提交管理员统一配置开通
4. 权限变更、回收、停用需走正式申请流程

## 5. 账号使用约束
- 账号单人专属，禁止共享、转借、共用
- 权限仅用于工作场景，禁止无关查询与越权访问
- 权限异常、菜单缺失，走正规申请反馈渠道
