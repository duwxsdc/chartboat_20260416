# 补录平台 ITBA 操作手册
## 1. 手册说明
本文档适用于ITBA日常查询、指导、咨询支撑场景，仅包含合规可操作范围，不含高危删除、数据导出、强制流程干预等能力外操作。

## 2. 基础登录
- 通过企业统一域名入口访问补录平台
- 使用个人域账号密码登录，账号专人专用
- 登录后根据自身角色展示对应菜单权限

## 3. 常用功能指引
### 3.1 配置管理查询
- 进入【补录配置管理】模块，支持按业务线、补录口、时间筛选
- 可查看现有配置信息、适用范围、使用规则
- 可为业务提供填写规范、参数说明、配置约束指导

### 3.2 权限查询指引
- 进入【权限管理】模块，查看当前角色权限清单
- 为权限不足用户，提供标准化申请流程指引

### 3.3 补录业务操作指导
- 引导业务按规范填写必填字段、格式要求、附件材料
- 解答常规操作卡点、页面提示、流程疑问

## 4. 通用操作规范
- 所有操作全程留痕，严格遵守岗位职责边界
- 仅在授权范围内开展查询与指导工作
- 系统异常、BUG类问题，统一反馈平台运维
- 严禁私存、截图、外泄平台业务敏感信息

## 5. 功能限制说明
- 不支持：数据导出、批量下载、数据拷贝
- 不支持：配置删除、配置强制修改、历史数据清理
- 不支持：跨部门审批干预、特殊白名单配置
