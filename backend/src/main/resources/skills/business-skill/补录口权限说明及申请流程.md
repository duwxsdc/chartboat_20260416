# 补录口权限说明及申请流程（业务录入人员版）
## 1. 权限概述
补录平台采用角色化权限管控，业务录入人员的权限仅针对指定补录口，仅能访问、操作自己权限范围内的补录口、菜单，确保数据安全与权责隔离。

## 2. 业务录入人员拥有权限
### 2.1 菜单权限
- 补录管理（仅可见自己有权限的补录口）
- 补录记录（仅可查询自己提交的补录记录）
- 待办事项（仅查看、处理自己的待办任务）
- 会计期查询（查看当前及历史会计期状态）
- 帮助中心（查看操作手册、FAQ）

### 2.2 操作权限
- 补录口数据录入、保存草稿、提交审核
- 未审核补录数据的修改、删除（仅自己提交的）
- 个人补录记录查询、详情查看
- 个人待办任务处理
- 会计期查询

### 2.3 无权限范围
- 其他业务人员的补录记录查看、修改
- 补录口配置修改、删除
- 数据导出、下载、拷贝
- 跨租户访问、跨补录口操作
- 审核权限、管理员权限

## 3. 权限申请流程
### 3.1 申请前提
- 确因工作需要，需新增补录口权限或扩展权限范围
- 已明确所需权限对应的补录口名称、业务类型

### 3.2 申请步骤
1.  联系本部门ITBA责任人，说明权限申请需求（补录口名称、申请原因）
2.  按要求填写《补录平台权限申请表》，提交部门负责人审批
3.  审批通过后，由ITBA责任人提交平台管理员配置开通
4.  权限开通后，ITBA责任人会通知申请人，申请人登录平台验证权限

## 4. 权限查询与维护
### 4.1 权限查询
1.  登录平台 → 点击【个人中心】→ 【权限查询】菜单
2.  页面显示当前拥有的所有补录口权限、菜单权限、权限生效时间
3.  若发现权限缺失或异常，及时联系ITBA责任人

### 4.2 权限变更与回收
- 权限变更（新增、扩展）：按“权限申请流程”重新提交申请
- 权限回收：因工作调整无需某补录口权限时，联系ITBA责任人提交回收申请
- 账号离职：部门管理员需及时通知ITBA责任人，回收该账号所有权限
