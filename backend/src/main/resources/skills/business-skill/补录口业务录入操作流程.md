# 补录口业务录入操作流程（业务录入人员版）
## 1. 流程总则
本流程适用于所有补录口的数据录入、提交、审核跟进、待办处理全流程，业务录入人员需严格按步骤操作，确保流程合规、数据准确。

## 2. 核心操作流程（通用版）
### 步骤1：登录平台
1.  通过企业统一域名入口访问补录平台
2.  输入个人域账号、密码，完成登录
3.  登录后核对个人信息，确认当前租户正确（若有误，联系ITBA责任人）

### 步骤2：找到对应补录口
1.  登录首页 → 点击【补录管理】菜单
2.  在补录口列表中，按业务类型、补录口名称筛选目标补录口
3.  点击补录口“进入”按钮，进入录入页面（无权限则无法点击，需申请权限）

### 步骤3：数据录入
1.  按页面提示填写各项字段，重点关注标红必填项
2.  需上传附件的，点击“上传”按钮，选择符合规范的附件并确认
3.  填写完成后，点击“保存草稿”（可暂停操作）或“下一步”（提交审核）
4.  若有校验失败提示，按提示修改字段，直至校验通过

### 步骤4：提交与审核跟进
1.  确认所有数据填写正确、附件完整后，点击“提交审核”
2.  提交后，补录状态变为“待审核”，可在【补录记录】中查看审核进度
3.  若审核驳回：查看驳回意见，修改对应字段后，重新提交审核
4.  若审核通过：补录流程完成，可在【补录记录】中查看最终状态

## 3. 待办处理流程
1.  登录平台后，首页【待办事项】模块显示个人待办补录任务
2.  点击待办任务，直接进入对应补录口录入页面
3.  按“数据录入-提交审核”流程完成操作，待办任务自动清除
4.  若待办任务逾期，页面会有红色提醒，需优先处理

## 4. 会计期查询流程
1.  登录平台 → 点击【系统设置】→ 【会计期查询】菜单
2.  页面显示当前会计期、起止日期、是否可补录状态
3.  若需查询历史会计期，可选择对应日期范围筛选
4.  若会计期已关闭，无法进行补录操作，需联系ITBA责任人咨询

## 5. 补录记录查询流程
1.  登录平台 → 点击【补录记录】菜单
2.  可按补录口、提交时间、审核状态筛选查询个人补录记录
3.  点击记录详情，可查看完整补录数据、审核意见、操作日志

## 6. 会计期查询流程（编码版）
1. 进入【系统设置】→【会计期查询】
2. 选择/输入租户编码/补录口编码
3. 系统返回当前6位年月会计期（如 202503）
4. 无编码无法查询
