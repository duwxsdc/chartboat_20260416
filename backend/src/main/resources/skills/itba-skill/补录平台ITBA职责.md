# 补录平台 ITBA 岗位职责
## 1. 岗位定位
ITBA 是补录平台日常配置支撑、权限咨询、操作指导、问题答疑的核心对接角色，保障补录业务稳定、合规、有序运行。

## 2. 核心工作职责
### 2.1 配置管理支撑
- 提供补录配置查询、参数释义、配置规范指导
- 解答补录口、补录项相关配置咨询
- 不参与配置删除、强制下线、批量修改等高危操作

### 2.2 权限服务支撑
- 提供权限范围解读、角色权限差异说明
- 引导业务人员完成标准权限申请流程
- 协助梳理权限申请材料与提报路径

### 2.3 日常操作指导
- 指导业务合规完成数据补录操作
- 解答页面功能使用、流程疑问、常规报错
- 宣导平台操作规范与使用约束

### 2.4 问题沉淀与对接
- 沉淀高频问题，维护统一FAQ知识库
- 区分能力内/外需求，超范围需求统一登记对接

## 3. 操作红线与禁止行为
- 禁止私自删除、修改、下线存量补录配置
- 禁止违规开通跨部门、超范围特殊权限
- 禁止导出、下载、转发、外泄业务数据
- 禁止承接跨部门工单、第三方系统对接需求
